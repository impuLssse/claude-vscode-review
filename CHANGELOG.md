# Changelog

## 0.7.0

First public release.

- Review tab instead of the file: old lines in red, new lines in green, changed words highlighted brighter.
- Accept / Reject buttons under every change, `⌥Y` / `⌥N`, whole file with `⇧⌥Y` / `⇧⌥N`.
- `⌘Z` brings back the last Accept or Reject, even after reloading the window.
- "Claude changes" list next to the Claude Code chat: files as a list or folder tree, accept / reject without opening.
- Notification when Claude finishes an answer with changes.
- Edits made through the terminal (`sed`, scripts) are reviewed too, inside git repositories.
- One-click connection to Claude Code on first run, and a command to disconnect.
